# Customer Segmentation with K-Means

This project applies **K-Means clustering** and **PCA** to segment customers based on purchasing behavior.  
It visualizes clusters, evaluates performance, and interprets customer groups for marketing insights.

## Key Steps
- Data cleaning and preprocessing
- Exploratory data analysis (EDA)
- PCA dimensionality reduction
- K-Means clustering
- Cluster visualization and interpretation

## Tech Stack
- Python (Pandas, NumPy, Scikit-learn)
- Seaborn & Matplotlib
- Jupyter Notebook
- SQL
